# 去 AI 味 · DeAI Studio

给 Codex 一句简短需求，让它从内容、结构、视觉与交互上作出更具体的选择。适用于图片、文字、前端页面、PPT 和文档。

```text
$deai 为当前目录的产品做一个主页
$deai 把这份资料做成给客户看的演示文稿
$deai 润色这篇文章，保留事实和我的语气
```

## 它怎样工作

一个 `deai` 技能入口按需读取五类参考。先识别受众、事实和用途，确定适合当前内容的表达方式，生成实际产物，再检查重复模板、功能状态和格式问题。简短任务不需要填写问卷；有资料时先读资料，缺少非关键偏好时由 Codex 选择。

| 模块 | 重点 |
| --- | --- |
| 图片 | 主次、媒介、光线与材质逻辑；编辑锁定用户喜欢的版本 |
| 文字 | 事实、观点和语气；删除空转句，保留具体的信息和合理的不确定性 |
| 前端 | 业务结构、真正可操作的界面与有目的的动效；不默认复制大标题加三卡片 |
| PPT | 受众要做的决定、证据与讲述节奏；按内容选择版式，保留必要的编辑能力 |
| 文档 | 体裁、阅读路径、标题层级、表格和排版；实际检查页码、换页和溢出 |

不会把所有作品都变成极简、米色、复古或手写风。紫色、渐变、卡片、对称、详细排线都是可用语言；明确品牌与内容需要时保留。默认约束的是没有用途的装饰和反复出现的模板组合。

## 安装与触发

从 GitHub Releases 下载最新的分发 ZIP。解压后按包内 `INSTALL.md` 操作；它会建立独立的本地 marketplace，不需要改动源码目录。安装后开启新任务，从技能选择器选择 **去 AI 味**，或使用 `$deai`。本插件允许隐式调用；是否自动匹配仍由宿主决定，不能保证每条请求都自动加载。

如果希望某个项目默认采用这些规则，可自行将 [项目指令片段](examples/AGENTS.deai.md) 合入该项目的 `AGENTS.md`。安装插件不会修改你的全局指令、原有技能或其他插件。

本地开发的个人 marketplace 可使用：

```sh
codex plugin add deai-studio@personal
```

`personal` 只适用于你的个人 marketplace 实际叫这个名字的情况。解压分发包使用包内 `INSTALL.md` 的独立 marketplace 名字。当前本机验收使用 Codex CLI 0.145.0；其他版本先检查 `codex plugin --help`。分发包按 Codex 插件结构制作，其他宿主需要适配，未做兼容承诺。

## 交互库与研究

可离线打开 [交互示例](skills/deai/assets/interaction-lab/index.html)，查看原创实现、状态转换、键盘操作和低动态效果。它是可复用模式库，具体采用哪种模式仍由业务决定。

[研究目录](docs/research/index.md) 收录一手方案、作者项目、设计与编辑方法。区分 Codex 专用技能、可移植指南、可复用代码和只供灵感参考的作品。第三方库不会在安装插件时自动装入你的项目；用到时核对当前栈、版本与许可。示例代码由本项目原创，未打包商业模板或作品素材。

## 能力边界

这是创作与审查技能，不是模型微调、AI 检测器或作者身份认证。目标是减少模板感并提高首稿质量；它不保证任意内容一次成功，也不应把生成结果宣称为真人作品、实拍、亲身经历或未经提供的客户案例。

核心指令和本地资产可离线读取，不需要专用 API 密钥或常驻服务。实际生图、浏览、PPT/DOCX/PDF 导出需要宿主相应能力；没有能力时会说明缺口，不能把提示词、Markdown 或 HTML 冒充已完成的图片、PPTX 或 DOCX。平台与外部工具原有的数据处理方式不变。

只修正文案的任务不会自发重做页面。只要求分析的任务不会擅自生成大量图片。现有品牌、稿件中的事实与用户明确选择优先于插件默认值。

## 验证与维护

[验证记录](docs/validation.md) 区分结构校验、真实试用和视觉判断。 [简短提示词样例](examples/short-prompts.md) 可用于复测。使用者的认可才是偏好证据；不会以内部打分宣布“彻底去 AI 味”。

[前后试用记录](examples/trials/README.md) 保留了基线、技能首稿及修正规则后的结果，包括首稿出现退步的地方。

[Office 格式样例](examples/format-proof/verification.md) 附 PPTX、DOCX 和生成源码；已核对原生对象与数据结构，本轮未进行 Office 页面渲染。

```sh
python scripts/build_release.py --validate-only
python -m unittest discover -s tests
python scripts/build_release.py --out dist
```

构建器只收录明确的插件目录，检查引用、路径与完整性；已有同版本 ZIP 会停止，避免悄悄覆盖发布包。分发包使用相对路径，可在不同用户目录安装。

卸载已安装插件：`codex plugin remove deai-studio@personal`；从独立分发 marketplace 安装时改为对应名称。先用本机 `codex plugin remove --help` 核对语法。删除插件不删除你已生成的作品；未被其他插件使用的分发 marketplace 可以另行移除。

当前通过 GitHub 源码仓库与 Releases 分发，尚未上架 Codex 的公开插件目录。公开目录上架仍需要平台审核与发布者资料；源码仓库本身不代表平台背书。
