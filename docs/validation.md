# 0.1.0 验证记录

环境：2026-09-05，Windows，本机 Codex CLI 0.145.0。下面区分结构、行为与内容结果；不将它们合并为“去 AI 味成功率”。

## 结构与分发

- 官方 `validate_plugin.py`：通过，检查插件 manifest。
- 官方 `quick_validate.py`：通过，检查技能入口格式。
- 发布构建器的 7 项单元测试通过，覆盖自足分发、缺失 Markdown/运行时引用、开发者绝对路径、越界引用、有效本地资产和外部模块名，以及跨构建时间的 ZIP 可复现性。测试使用隔离的临时目录，不改用户项目。
- 本地 CLI 已从个人 marketplace 正确发现 `deai-studio`，来源为实际插件目录。最终安装与 ZIP 完整性在交付时另外核对；本文件不预先声称安装完成。

构建前还会以 `python scripts/build_release.py --validate-only` 检查分发文件的相对 Markdown 引用、HTML 直接资源引用、CSS `url()`、JS 字面量相对导入及未完成占位符；构建过程重复执行这一检查。它不是完整 JS/CSS 解析器，不检查动态拼接 URL 或外部包是否已安装。压缩包只收录允许的插件目录与文件类型，不包含客户图片、历史聊天、部署资料或运行依赖。

## 原创交互

查看 [行为结果](../skills/deai/assets/interaction-lab/test-results/results.json)、[桌面截图](../skills/deai/assets/interaction-lab/test-results/desktop.png)、[390px 截图](../skills/deai/assets/interaction-lab/test-results/mobile.png)。

6 种模式，13 项自动检查通过：离线加载、项目预览、分段键盘、原生展开、分段深链接、提交成功/失败/重试、连续隐藏及撤销、局部阅读进度、桌面和窄屏布局、减少动态效果、无 JavaScript 退化，以及无脚本错误或外发网络请求。另已实际查看桌面和移动截图。

测试使用本机已有 Playwright 驱动无头 Microsoft Edge，以 `file://` 打开；没有起服务器、没有接管用户浏览器。页面本身不需要 Playwright。可在示例目录按 [说明](../skills/deai/assets/interaction-lab/README.md) 重跑。

未做真实手机、读屏软件、独立 Chrome、Safari 或 Firefox 实测。13 项通过不等于完整无障碍认证，也不证明迁移到另一个项目后仍自动通过。
