# 原请求

给客户写约1页网站维护服务范围，包含内容更新、每月一次依赖检查；不含新功能开发；紧急故障优先排查但未承诺响应时间。没有报价和签约日期。

# 实际产物

# 网站维护服务范围

本服务围绕现有网站开展日常维护，主要包括内容更新、依赖检查，以及网站故障的排查与处理。具体范围如下，供双方确认。

## 内容更新

在现有页面与功能范围内，更新客户提供并确认的文字、图片、链接及其他可替换内容。更新前核对修改位置与最终素材，完成后检查相关页面的展示和链接是否正常，并向客户说明更新情况。

涉及新增页面结构、改变现有业务流程或增加交互能力的需求，先明确工作内容，再另行商定。

## 每月一次依赖检查

每月检查一次网站使用的依赖，查看版本状态、已公开的安全问题及可能影响网站运行的兼容性事项，并反馈检查结果与处理建议。

依赖检查不代表每月自动升级全部依赖。需要升级时，先判断兼容性与影响范围，再确认具体处理安排。涉及较大版本迁移或现有功能改造的工作，另行确认范围。

## 故障排查

对网站访问异常、页面报错及现有功能异常进行排查。客户提供问题页面、出现时间和可复现步骤，有助于定位原因；我们将根据排查结果说明已知问题、影响范围和后续处理建议。

紧急故障优先安排排查。实际处理安排取决于故障情况、必要权限、资料是否齐全及相关服务状态，本范围不承诺固定响应时间或修复完成时间。涉及托管、域名或其他第三方服务的问题，将说明所需的配合事项。

## 范围之外

本服务不包含新功能开发。新增业务模块、系统集成、网站整体改版及超出现有页面结构的建设需求，应另行明确范围与安排。

如维护过程中发现需求超出本范围，将先向客户说明原因及拟开展的工作，待双方确认后再处理。

## 配合与交付

客户负责提供经确认的更新内容、必要的管理权限，并指定需求确认人。维护完成后，将说明已处理事项、验证情况，以及仍需客户或第三方配合的部分。

本说明用于界定服务内容。服务费用、起止时间及其他商务条款由双方另行约定。
