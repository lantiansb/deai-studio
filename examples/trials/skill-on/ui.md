# 自行车维修店主页内容与交互规格

## 原始请求

给这家店设计主页内容结构及按钮/交互规格，简洁但有记忆点。品牌已指定紫色渐变、圆角按钮，不能换品牌，不需写整个前端代码。

## 实际产物

页面让附近骑车的人先确认能处理哪些问题，再找到到店时间和地址。沿用品牌紫色渐变与圆角按钮，把“先检查，再报价”作为页面最容易记住的一句话。

### 主页内容顺序

**1. 页首：一眼看懂这家店**

店铺标识文字：自行车维修 · 新桥路18号

主标题：先检查，再报价。

正文：补胎、刹车调试、基础保养。自行车有这些维修保养需要，可以到店看看。

营业信息：周二至周日 10:00–19:00

主按钮：营业时间与地址

次链接：查看维修项目

**2. 维修项目：用一张清楚的清单说明范围**

区块标题：这几件事，可以来店里。

用三行左对齐清单呈现：

| 项目 | 行内文字 |
| --- | --- |
| 补胎 | 车胎漏气，需要补胎 |
| 刹车调试 | 刹车需要检查和调试 |
| 基础保养 | 给自行车做一次基础保养 |

清单下方直接写：先检查，再报价。

**3. 到店信息：能直接带走的地址**

区块标题：新桥路18号见。

地址：新桥路18号

营业时间：周二至周日 10:00–19:00

按钮：复制地址

### 视觉规格

- 紫色渐变集中用于主按钮与标题旁的一条短线。短线连接“先检查”和“再报价”，表达实际顺序；保留品牌现有渐变色值，不另换配色。
- 圆角按钮保持品牌规定的形状；主按钮实心渐变，复制按钮采用紫色描边，正文区域使用便于阅读的浅色底。
- 桌面首屏左侧放标题和正文，右侧放地址与营业时间；窄屏按标题、正文、营业信息、按钮的顺序排列。维修项目始终为纵向清单。
- 正文建议16px、行高1.6；主标题桌面40px、窄屏30px。不要强制断开“先检查”或“再报价”。
- 文字与背景对比度以4.5:1为验收条件；渐变较亮的位置若不满足条件，增加按钮文字下方的深色底层，保留可见的品牌渐变。
- 所有内容首次加载即可读。页面不使用入场动画；记忆点由修车顺序和紫色渐变承担。

### 按钮与交互规格

| 控件 | 触发及结果 | 状态与失败处理 |
| --- | --- | --- |
| 营业时间与地址 | 使用原生链接跳转到到店区块 `#visit`；键盘Enter与触屏轻点均可触发 | 默认显示渐变底；聚焦显示清晰外描边；按下加深底色。重复点击仍定位同一区块，无等待或禁用状态 |
| 查看维修项目 | 使用原生链接跳转到维修项目区块 `#services` | 默认带下划线；键盘聚焦显示外描边；不依赖悬停才能辨认。无需脚本即可跳转 |
| 复制地址 | 点击或键盘Enter/空格，将“新桥路18号”写入剪贴板 | 默认“复制地址”；写入期间显示“正在复制”，防止重复执行；真实成功后显示“已复制”，并在按钮旁显示“地址已复制”；失败恢复按钮并显示“复制未成功，请选中下方地址手动复制” |

### 实现细节与适用条件

- 原生链接保留有效目标。脚本可用时，跳转后把焦点移至目标标题；目标标题允许程序聚焦，且不被页首遮挡。保留地址和营业时间的完整文本。
- 复制结果通过 `aria-live="polite"` 播报，反馈留在按钮旁，成功或失败均保留按钮焦点。再次点击可重新复制，不以计时器伪造成功状态。
- 仅在脚本与剪贴板能力可用时显示复制按钮；没有这项能力时，保留可选中的地址文字。拒绝剪贴板权限时走失败提示。
- 点击区域至少44×44px；文字链接也保留足够间距。窄屏单列，无悬停专属内容。
- 不强制平滑滚动。系统开启减少动态效果时，同样直接跳转，控件状态即时改变。
- 当前地址未提供城市，因此本稿不设置地图导航链接。需要地图导航时，先补齐城市并核对地图地点；现阶段主操作是查看并复制地址。

交付范围为内容与交互规格，未实现页面，也未进行浏览器、窄屏或辅助技术实测。
