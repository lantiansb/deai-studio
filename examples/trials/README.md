# 短提示词试用：原始结果与复测

日期：2026-09-05。5 个构造请求，覆盖文字、UI规格、演示逐页稿、正式服务范围和不确定性表述。这里的店铺、门店试点、服务范围都是虚构测试场景，不是 EEBadge 的事实或客户案例。

## 怎么做的

基线代理没有读本插件、研究或其他结果；另一位独立代理读技能和对应领域参考，使用相同业务资料完成 5 个请求。两者均未联网，未额外指定不同模型。保留各自实际收到的请求与完整产物：UI请求的店铺事实在基线中直接附在题内，在技能试用中由同组写作请求提供，因此不是逐字完全相同的独立提示。

评审后修正了三处一般性规则：短介绍可以自然结束；正式短文不重复边界说明；幻灯正文不混入制作指令。同一试用代理按原请求做了 3 个第二轮产物。首轮结果未修改，第二轮明确标记为修订复测。

这不是盲评或统计实验：每种请求只有一份基线和一份技能首稿，3 项有一次规则修订后的复测；没有控制随机种子、记录精确内部模型版本或进行多模型、多用户测量。结论仅限这些具体产物，不能报告首稿成功率。

## 用于以后复测

保留原请求，先制作真实产物，再检查事实和用户保留项，最后由实际使用者判断语气与风格。不要将这批样例训练成固定答案；下一批应加入不同主题、作者语气、密集应用、长文档和用户已经认可的复杂视觉风格。

UI与演示的这些比较只验内容和规格。实际离线交互代码另见 [交互实验](../../skills/deai/assets/interaction-lab/index.html)。它的浏览器检查不等于这些UI规格已实现。
