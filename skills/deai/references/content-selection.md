# 内容取舍：上下文不等于成品

先决定哪些消息值得出现，再润色它们。筛选依据是读者的用途、当前状态和用户指定的表达；不按词频、对话篇幅、语气强度或模型是否反复记住某句话分配页面位置。

## 给信息一个去处

在内部对候选内容做以下判断；短任务不必写表，多媒介任务可记在制作简报中。

| 去处 | 判断依据 | 做法 |
| --- | --- | --- |
| 主内容 | 帮读者识别对象、理解主张、感受明确的品牌表达或完成当前操作 | 直接呈现，给相应视觉权重 |
| 按需说明 | 确实有用，但不是当前阅读或操作的前提 | 放到相关说明、可发现的展开项、注释或附录；不重复铺满每个区域 |
| 仅用于执行 | 调整风格、工具、交付格式、部署范围或制作方法 | 指导实现；需要向委托者报告时放交付说明，不直接写成作品正文或图中标签 |
| 不采用 | 偶然比喻、已被替换的方向、没有贡献的重复、与主题无关的背景 | 从本次成品去掉，不为了留痕换个词写回来 |

同一事实可随任务改变去处。产品处于开发阶段：纯风格展示不需要每屏状态条；涉及是否可购买、交付或已实现功能时，状态可能直接影响决定，应在相应入口说明。动作失败、费用、数据删除、权限、保存结果等不能移到用户操作后才发现的位置。

不要把所有不确定项列成待确认清单。只保留影响本次产物或下一步决定的缺口；不相关的未提供价格、日期、团队规模等无需占位。

## 先选择，再转译

1. **理解职责。** “更像人工做的”“不要密集颗粒”“参考某品牌的节奏”通常是制作要求，不是标题、图案或宣传主张。品牌名作为自有品牌或用户明确要求的内容时则应保留。
2. **确定实际内容。** 对文字、UI、PPT和文档，选定真正要读到的消息。对图片，分开主体、构图、媒介和实际出现的字样。未要求文字且不需要标注的插画，可明确不放文字；需要文字时列出要印出的准确内容。
3. **约束有边界。** 可以在授权范围内拟标题或补足场景构图，不默认向用户逐句询问。但不要把聊天里提到的工具、服务器、风格术语或否定要求自动变成标题、人物、道具、图标、脚注。
4. **转译为行为或构图。** “只做本地预览”首先约束真实功能；若按钮会被理解成上传、保存或发送，应在该操作处用简短、准确的提示。不要用满屏声明补救一个误导的按钮。“保留左侧排字空间”是留白，不是在图里画一张写着“排字空间”的牌子。

## 做完后的两向检查

**多写了什么？** 通读所有可见文字、图中标牌、图注和重复小字：离开制作对话后，读者为何需要它？删去后是否真的损失任务信息或明确的表达？没有贡献就删除，不只缩小字号或挪到页脚。标题已说明状态时，正文必须补充有效内容，否则可省。

**少写了什么？** 再对照原材料核事实、条件、单位、时间范围、责任和用户保留项。不得因减法把“可能”改成“已证明”、把“预览”暗示成“已保存”、把报价排除项藏进不可见备注，或删除让读者正确理解图表的样本与口径。

必要的作者/来源标注、已确认披露要求与作品元数据照常保留；“少写过程”不授权伪称人工创作、客户实拍或已有业绩。

## 跨媒介例子

以下为构造示例，不是待套用文案。

- **网页：** 委托者说“部署在服务器甲，只开放主页端口”。这约束部署，不应变成主页卖点。真实导出按钮旁的格式、尺寸和错误提示仍属于使用内容。
- **图片：** 请求“画一位蓝衣信使，像热血动画的张力但用原创设计，图上只写 ORBIT”。画面保留主体和 ORBIT；不加“原创不侵权”“去AI版”等标牌，也不借机抹去已有水印或标注。
- **PPT：** “给主管看，别套三张卡片，试点处理120笔，其中9笔复核，未比较时长。”正文呈现120和9及适当的口径；不写“拒绝三卡片”，也不能推出效率提升。
- **文档：** 服务范围只含一次设计和两轮修改，不含开发。精简时保留这些条款；省去“本说明未约定其他事项”在每节的重复，不添加未经约定的新义务。
- **反例：** 文章主题本身是“去AI味”，或用户要求忠实转录一句含“模型生成”的引文，这些词就是内容，不能自动删除。

## 依据与适用范围

这些规则是本插件的综合设计，不是单篇资料已验证的通用模型机制或一稿成功保证。

- [NN/g：Aesthetic and Minimalist Design](https://www.nngroup.com/articles/aesthetic-minimalist-design/) 支持按任务减少无关信息，同时保留必要功能；不要求视觉风格统一极简。
- [GOV.UK：User needs](https://www.gov.uk/guidance/content-design/user-needs) 支持从读者需要而不是已有素材数量决定内容。
- [Impeccable：distill](https://github.com/pbakaus/impeccable/blob/main/skill/reference/distill.md) 与 [clarify](https://github.com/pbakaus/impeccable/blob/main/skill/reference/clarify.md) 提供删重复和按状态组织信息的思路；不照搬固定删字比例、色数或字体数。
- [OpenAI：GPT Image Generation Models Prompting Guide](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide) 支持把图中准确文字和画面约束分别说明。
- [Anthropic：Effective context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) 支持选择对当前任务有用的上下文；本文把它用于内容进入产物前的筛选，是我们的应用推论。
