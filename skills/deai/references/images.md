# 图片：先组织画面，再分配细节

## 新图

从用途、主体、动作、观看尺寸和主媒介建立画面。给图像工具的规格包括：构图与裁切、线条或光照逻辑、细节重点、真实参考的职责以及必须保留项。使用宿主实际提供的图像工具，不能以提示词或占位图代替出图。

| 媒介 | 有用的决定 | 保留的品质 |
| --- | --- | --- |
| 动漫/漫画 | 线条轻重、发束结构、色块与阴影层次、背景主次 | 角色辨识点、表情、服装结构；需要的排线和棱角 |
| 水彩/水粉 | 笔触方向、色块连接、边缘干湿和纸白分布 | 合理的水色过渡和有作用的纹理，不统一磨平 |
| 厚涂/数字绘画 | 大体块、边缘虚实、材质差别、视觉焦点 | 连续明暗与体积，不强行改赛璐璐 |
| 摄影 | 动作与观察位置、可信光源、材质反射、对焦目的 | 清晰可以自然，真实感不需要人为加脏或噪点 |
| 产品图 | 真实几何、部件、文字、接触与比例 | 可光洁，但不能改接口、开孔或虚构现货外观 |
| 小尺寸图案 | 安全裁切、可读剪影、明暗分组 | 核心部位在实际尺寸可辨，不以微纹理充当细节 |

图像由动作、环境和媒介形成特色，不依赖“8K、大师级、极致精致”等词。新图描述本来需要的构造，不先堆高细节再统一要求“去AI”。

## 编辑

先看实际图片，指出最多四个有证据的问题。保存原图并选择用户更喜欢的版本作为参考；每张参考明确提供身份、构图、风格或产品结构，不混淆其职责。

保留项包括渲染密度与边缘处理。用户喜欢简洁平涂时，不以“恢复体积”为由重新加回渐变与高光。用户喜欢精细画法时，不自动减少必要的结构性排线。

| 可见问题 | 定向编辑 |
| --- | --- |
| 密集细发丝/碎亮块 | 合并成沿结构的发束和明暗，不扩大头发体积或改变发型 |
| 所有材质同样油亮 | 分别整理布、皮肤、金属的受光与反射，保留合理高光 |
| 背景和主体同样繁忙 | 降低次要区域高对比细节，保留场景需要的信息 |
| 随机颗粒/纸纹覆盖全图 | 只清理无制作逻辑的叠层；保留符合媒介的笔触 |
| 角色被“简化”成另一个人 | 回到身份参考恢复识别点，不能以少细节解释漂移 |

减少细节的下一轮只做可定位的减法，不同时加入新光源、新材质、新配件或重渲染。必要的脸颊纹、徽记、链条、齿形面罩等属于设计，不是自动删除目标。

## 可复用提示结构

按 [内容取舍](content-selection.md) 先区分画面指导与实际字样。需要图中文字时单列准确文本；无需文字的插画不自动添加标签、口号或说明。聊天里偶然提到的物件和比喻，也不因此获得入画资格。可在授权范围内补足构图，不能把制作约束逐词画成场景内容。

```text
用于什么、什么比例和观看尺寸。
主体、动作、构图；参考各自提供什么。
主媒介：线、色、明暗或光照如何配合。
重点刻画什么；次要区域怎样概括。
实际出现的文字（如需要，给出准确内容）。
必须保留什么；本轮只改变什么。
与实际问题相关的少量排除项。
```

不要机械保留所有字段或固定用英语。使用可执行的正向规格，排除项只对应已观察的问题。

## 看结果

检查主体身份、产品结构、文本与解剖，再看原尺寸和实际显示尺寸的焦点、材质、细节与风格。有无新问题：金属过分光滑、背景层次被清空、轮廓全加粗、脸型变软、图案更有塑料感？“更少细节”与“更好看”分别评价。

一轮默认一个候选；用户要求对比才做少量有区别的候选。保留实际提示、参考路径、原始输出、可见改善和退步。图像工具未暴露模型版本、seed或内部会话状态时不声称控制了它们。

本模块移植自本项目已有图片技能；方法与试验边界见 [证据说明](../../../docs/research/codex-images.md)。本版没有携带客户图片或试验中的动漫角色图片。
