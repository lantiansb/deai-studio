# 前端：产品结构、视觉身份与行为

## 先确定页面在做什么

阅读真实路由、组件、设计令牌、数据与已有交互。落地页回答“这是什么、依据是什么、如何开始”；工作界面帮助完成任务；内容站帮助定位和阅读。不要把这三类页面都做成营销落地页。

先确定页面的实际内容顺序及主操作，再安排视觉。真实产品、作品、数据、流程或比较对象应承担主要表达；不以任意插画和装饰KPI填补资料缺口。无照片时可以用文字、结构或明确示意，不冒充实拍。

遇到背景信息很多时，按 [内容取舍](content-selection.md) 决定哪些内容在当前页面出现。制作方式、宿主工具、部署约束和审美口令默认不进入产品文案。相关能力边界放在影响选择或操作的位置；不要把同一句说明变成每屏的装饰脚注。减少无关文字不要求削弱用户明确选择的大字、色彩或动效。

## 让控件的形式来自用途

| 实际需要 | 优先形式 | 常见失误 |
| --- | --- | --- |
| 在多个对象间检索比较 | 可扫描列表、适当列对齐、筛选与真实结果数 | 每个对象做成巨卡，主要信息被装饰挤走 |
| 完成单一操作 | 清楚动作词、按钮与相关输入相邻 | “开始你的旅程”式按钮，点击后没有真实动作 |
| 解释价格、配置或参数差异 | 同口径对照、选择后更新同一预览 | 硬凑三档和“最受欢迎”，没有真实价格支持 |
| 展示案例或创作者作品 | 索引、作品本身、明确细节与项目说明 | 大量通用插画和虚构客户评价 |
| 处理密集业务数据 | 明确行列、稳定定位、批量操作与状态 | 追求留白而降低扫描效率 |
| 理解过程 | 符合实际顺序的步骤或关联图 | 为布局凑步骤、虚构进度或隐藏关键条件 |

原生熟悉控件有助于使用。不要为独特而隐藏导航、重写键盘习惯或移动点击目标。已有组件系统是优先来源；只在需要更好的行为或表达时替换。

**交互语义。** 按内容角色和用户明确需求处理光标与选择：在展览式品牌场景中，对不承担复制任务的艺术字、装饰性标题局部使用 `user-select: none` 和 `cursor: default`，保留标题语义与可访问名称，避免普通展示文字呈现可编辑的插入光标感。真实可点击的链接和按钮保留 hover 反馈、`cursor: pointer` 和键盘 `focus-visible`；真实输入、可编辑区以及需复制的正文、地址、数据保留选择与编辑能力。非编辑文字不用 `contenteditable`，非控件不以虚假 `tabindex` 制造交互感。这项展示偏好不推广为文档正文或所有网站的全局禁选规则。

## 视觉决定

- 给字号、字重、行距、宽度、颜色和间距分配语义角色。标题是信息，不靠极大尺寸、任意断行或小字母标签补气势。
- 依据内容建立对齐和密度。统一基础令牌，允许长短、重点和内容关系影响区域大小；不强制所有区块同高、同列数。
- 品牌色用在需要识别或行动的位置。客户指定紫色渐变就保留它，并处理文字对比和阅读背景，不擅自全改为黑白。
- 视觉重点可以鲜明：产品配置变化、作品大图、直接可用的示范、清楚的数据关系。少量有意图的差异比全站同时有动效更容易被记住。
- 图标用来加速识别，标签用来说明；没有图标需要的地方不强行给每段加一个。装饰编号只有在索引或步骤上有意义时使用。

## 交互决定

阅读 [交互选型](interaction-library.md)，为每个重点动作确定：触发、起止状态、显示依据、中断、键盘/触屏替代、失败与低动态效果。

普通操作从直接、短促、局部的反馈开始；时长由距离、对象大小和用户控制方式调整，不把一个固定毫秒值应用到全站。正在保存显示真实请求状态；只有已知实际进度才显示百分比。切换和排序要能解释对象去了哪里。

不要给所有按钮加磁吸、所有标题逐字出现、所有背景加光点、所有滚动加视差。若品牌体验明确需要表现性运动，将其集中在一个主要场景，并保证可跳过、可中断和窄屏版本。

## 实现与验收

- 创建可用页面和真实路由。CTA、筛选、选择、展开、复制、保存等有实际效果；缺少后端时明确演示状态与接口缺口，不伪造提交成功。
- 控件有默认、focus-visible、按下、禁用及相关等待/错误状态。焦点位置与可见内容同步；不要只靠 hover 或颜色透露关键信息。
- 初始内容不依赖动画才可见。JS失败时至少能读主要信息；原生链接与表单可保留有意义的退路。
- 检查实际桌面与窄屏页面、长内容、空结果、错误路径和 reduced-motion。能看截图才声称检查了视觉；能实际操作才声称验证了行为。
- 尊重项目实际浏览器、性能预算和依赖。清理监听器、观察器、计时器与退出中的元素；不在未挂载或离屏时循环测量。
- 风格复审询问“为什么这家公司/这项任务适合这种表达”，不以是否出现某个颜色或组件自动判定好坏。
