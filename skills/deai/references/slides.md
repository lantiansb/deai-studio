# 演示：让页面呈现判断与证据

## 先确定观看方式

现场讲述、会前阅读、技术教学、客户提案需要不同密度。资料未说明且请求是“做汇报PPT”时，可自行按可讲述且可独立扫读的结构制作，保留关键条件在页内，次要讲述放备注。用户已有模板、母版或品牌时优先沿用。

大纲不是固定目录：逐页先写这页要传达的消息、已有证据、必要限定与来源。目录和练习页无需强行写成断言。数据不足时允许用问题或计划作标题，不为有气势而把假设写成成果。

逐页使用 [内容取舍](content-selection.md)：制作口令不变成页内标题，次要推导可进附录或讲者备注；理解该页结论所必需的限定仍留在页内。画面已有证据时，不为填满版式重复一遍所有文字。

## 内容关系决定版式

| 内容关系 | 合适的页面组织 |
| --- | --- |
| 有依据的发现 | 句子标题＋主证据图表＋直接标注＋范围或出处 |
| 工作原理 | 系统关系图＋局部解释＋边界；节点与箭头有真实语义 |
| 做选择 | 按真实候选数量排列的比较、权衡或成本构成；说明依据 |
| 随时间变化 | 共同尺度的趋势、时间条或小多图；区分已发生与拟进行 |
| 阅读型证据 | 摘要、主文、表图与方法侧注；必要时拆页或改为配套报告 |
| 教学演示 | 具体例子、关键标注、可执行步骤、可观察结果 |

同类对比页重复结构有价值。整套保持字体、网格、配色和标注规范一致，页面关系可以不同；不是轮换皮肤，也不是每页三卡片。避免没有来源的KPI、凑三个优势、整页装饰图和过多抽象图标。

## 图表与文字

- 数字、单位、分母、期间、样本和不确定性随结论一起保留。观察到变化不等于证明因果。
- 回复数、使用数、总数等嵌套或不同状态不能当互斥项相加；无法证明的包含关系不画成漏斗。
- 不为视觉对比改变轴或删去限制条件。需要计算的新数值保留公式与口径；不要由中位数差推算没有样本量支持的总工时节省。
- 标题写实际消息，图注写读图所需信息；现场稿的备注放讲述逻辑，不能把关键限制只藏在备注。
- 正文只呈现受众需要的消息、证据和限制。“不画成漏斗”“不使用三卡片”等制作者检查语句留在源码或设计说明，不放在最终页面正文。交付逐页稿时也明确区分实际正文与制作规格。
- 数据与精确文字由原生排版生成。图像工具只在确有视觉需要时制作示意插图，不能生成不存在的实验照片或客户证据。

## 选择真实输出路线

| 用户需要 | 路线与限制 |
| --- | --- |
| 可编辑PPTX | 使用宿主可用的原生对象生成能力，如 PptxGenJS 或相应办公工具；文字、表格、能支持的图表与形状保持可改 |
| 图片故事/整页视觉稿 | 可用图像工作流，但说明整页为图片，保留逐页文字与源提示；不能称为全部可编辑 |
| HTML技术演示 | 按项目选 reveal.js/Slidev/Marp 等；保留源码并验证静态导出，不能以HTML冒充PPTX |
| 研究材料多格式发布 | 可按可用环境选 Quarto 等；不同输出各自检查，不推定所有图表都可编辑 |

库本身不提供审美；不要因某个引擎容易输出便改变用户要求的格式。Slidev 和 Marp 默认PPTX属于整页图片路线；Marp实验性可编辑模式需要额外环境和逐页验证。具体版本核查见研究文档，不根据文件扩展名判定编辑能力。

## 交付检查

先核正文、图表数据、限定与页序；再实际渲染所有页面，检查整套缩略图节奏及重点页实际尺寸。关注溢出、重叠、细小标注、缺字体、图文裁切、备注、链接与导出页数。

使用坐标检查只能发现一部分问题，框内文字仍可能溢出。读取OOXML可以核对原生文本、表格和图表是否存在，但不证明所有内容可编辑。无法渲染时明说“未做视觉验证”，不声称完美排版。

交付用户需要的格式，保留能继续修改的源文件；简短说明主要判断和未解决的资料缺口。无需把内部创作清单放入演示正文。
